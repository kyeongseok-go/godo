# Pace — 개인용 할 일 앱 기능 명세 / 완료 체크리스트

TickTick + Todoist 실사용 조사(`research/`)에서 뽑은 기능. 나 혼자 쓰는 로컬 앱이라 배포·계정·결제는 없다.
유료 플랜 한도(프로젝트 5개, 필터 3개, 7일 기록 등)는 전부 제거한다.

## 기술 결정
- Vite + React + TypeScript, 상태 Zustand, 저장 IndexedDB(Dexie), 테스트 Vitest + Playwright
- 서버·계정 없음. 데이터는 브라우저 안에만 있고 JSON 내보내기/가져오기로 백업한다.
- 디자인 방향: Swiss/에디토리얼. 종이색 바탕, 잉크 블랙, 주홍(vermilion) 한 가지 신호색. Pretendard + Fraunces(숫자·제목).

## 구현 현황 (2026-10-23)
F12를 제외한 모든 항목을 구현했다. 단위·컴포넌트 테스트 2,642개(구문 96% · 함수 96% 커버리지), Playwright E2E 81개(핵심 흐름·접근성 axe 라이트/다크·PWA 오프라인 포함)가 통과한다.
