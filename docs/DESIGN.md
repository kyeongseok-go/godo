# Pace 디자인 기준 (2026-10-23 개편)

## 왜 바꿨나

1차 디자인은 "Swiss/에디토리얼" 방향이었다. 크림색 종이 바탕(#f4efe4) + 세리프 제목(Fraunces) +
주홍 강조(#c8360f) + 굵은 괘선 + 대문자 eyebrow 조합이다.
이 조합은 지금 AI가 만든 화면에서 가장 흔하게 나오는 기본값이고, 실제로 쓰는 사람에게는
글자가 크고 선이 굵어 한 화면에 들어오는 정보가 적다는 문제가 있었다.

## 무엇을 보고 정했나

사용자가 2026-09-29에 직접 조사해 둔 [디자인 레퍼런스 지도](https://claude.ai/artifact/DTSPMh9rf2ZKvnVQ4n4tuW)의
추천 조합(무료 갤러리 + shadcn/ReUI 레지스트리)을 길잡이로 삼고, 실제 제품 화면을 직접 열어 확인했다.

| 본 것 | 가져온 것 |
| --- | --- |
| Linear | 차가운 중성 회색, 13~14px 조밀한 줄, 색은 상태에만 |
| Amie | 흰 패널 + 둥근 모서리 + 떠 있는 것에만 그림자 |
| Sunsama | 하루를 세로 열로 보는 구성, 시간 블록은 채운 색 면 |
| Morgen | 푸른빛 도는 어두운 테마, 오늘 날짜는 작은 원형 배지 |

공통점은 분명했다. **바탕은 차가운 회색, 구분은 면과 간격, 색은 내용(시간·우선순위·상태)에만.**
크림색 종이와 세리프 제목을 쓰는 제품은 한 곳도 없었다.

## 지금의 기준

### 색 (`src/styles/tokens.css`)
- 바탕은 차가운 회색(`--paper` #f4f6f8 / 다크 #0f1318), 표면은 흰색(다크 #161c23).
- 강조는 **짙은 청록 하나**(`--accent` #0a6a60 / 다크 #3cc9b4). 버튼·선택 상태·포커스가 전부 이 색이다.
- **호박색(`--now`)은 "지금"에만** 쓴다. 하루 리본의 현재 시각 눈금, 그것뿐이다.
- 우선순위·기한 초과·완료는 의미색(`--p1`~`--p4`, `--danger`, `--ok`)을 쓰고 장식에는 쓰지 않는다.

### 글자
- Pretendard 한 가족만 쓴다. 제목은 굵기(700)와 자간(-0.02em)으로 구분한다.
- 본문 14px, 작은 글 13px. 제목은 화면을 덮지 않을 만큼만 키운다(최대 1.9rem).
- 시각·분량은 `font-variant-numeric: tabular-nums` 로 자리를 고정한다.

### 구조
- 목록은 평평한 줄, 떠 있는 것(대화상자·팝오버·토스트)만 그림자를 쓴다.
- 굵은 잉크 괘선(2px)을 전부 없애고 1px 규칙선으로 바꿨다.
- 본문은 `--measure`(72rem)까지만 넓어진다. 넓은 화면에서 한 줄이 끝까지 늘어나지 않게.

### 하루 리본 (`src/features/plan/ribbon.ts`)
화면에서 눈에 띄는 자리는 하나만 쓴다. 그 하나가 **오늘 화면 맨 위의 하루 리본**이다.
근무 시간을 가로로 펼치고, 시각이 정해진 일을 우선순위 색 면으로 얹고, 지금 시각을 호박색으로 짚는다.
용량 막대(계획 합계 / 용량)가 이 리본 안에 들어간다.

### 하지 않는 것
- 대문자로 늘려 쓴 라벨, 제목 위의 번호 매기기(01/02/03 — 실제 순서가 있는 단계에만 쓴다).
- 모든 것을 같은 둥근 카드에 담기, 같은 그림자 반복, 장식용 그러데이션.
- 세리프 제목, 크림색 바탕.

## 마크
다섯 눈금 중 가운데가 호박색인 도형. 하루의 눈금과 "지금"을 그대로 본뜬 것이고,
파비콘·앱 아이콘(`public/favicon.svg`, `public/icons/`)과 사이드바가 같은 도형을 쓴다.
워드마크는 소문자 `pace`.
