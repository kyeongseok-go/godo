# godo 디자인 기준 (2026-10-24 2차 개편)

## 왜 또 바꿨나

1차(크림색 종이 + 세리프)를 버리고 2차에서 차가운 회색 + 청록으로 갔다. 정보 밀도는 좋아졌지만
**각져 보였다.** 실제로 쓰면서 걸린 것들:

- 목록이 화면 끝까지 꽉 찬 줄 + 전폭 구분선 → 표(스프레드시트)처럼 읽혔다.
- 집중 화면의 시작 버튼이 모서리 0의 검정 전폭 사각형이었다.
- 모드 전환이 검정으로 꽉 찬 사각 탭이었다.
- 캘린더가 폰에서 7열 격자라 일정 제목이 전부 `운동...` 으로 잘렸다.
- 버튼마다 1px 회색 테두리가 둘러져 있었다(`border: 1px solid var(--rule-strong)` 가 71곳).
- 하단 탭바 가운데 큰 원형 + 버튼은 안드로이드(머티리얼) 문법이다.

3차 방향은 **"아이폰 기성 앱의 손맛"** 이다. 면은 둥글게 묶고, 테두리 대신 채움색으로 구분하고,
누르면 반응하고, 뜨는 것만 그림자를 쓴다.

## 무엇을 보고 정했나

추측하지 않고 1차 문서와 실제 제품 CSS 를 재서 정했다.

| 본 것 | 가져온 것 |
| --- | --- |
| Apple HIG — Accessibility | 터치 영역 **44×44pt**(기본), 28pt(최소) |
| Apple HIG — Typography | iOS Dynamic Type 단계(Body 17 / Caption 11)와 **SF Pro 트래킹 표** |
| Apple HIG — Dark Mode | 깊이는 그림자가 아니라 **표면 밝기**(base ↔ elevated)로 낸다 |
| Apple HIG — Materials | 바는 뒤가 비치는 재질, 콘텐츠 레이어에는 쓰지 않는다 |
| apple.com CSS 실측 | 전환 **320ms 주력 / 240ms 보조**, `cubic-bezier(0.4, 0, 0.6, 1)`, 캡슐은 `50%` 가 아니라 큰 고정 px |
| Linear CSS 실측 | `:active { transform: scale(.97) }`, hover 를 `@media (hover)` 로 격리, 높이 44px 토큰 |
| Amie CSS 실측 | 그림자는 알파를 키우지 않고 **겹을 쌓는다**(y=blur, spread=−blur/2, 알파 고정) |

**자간은 통념과 반대다.** SF Pro 트래킹은 12px 에서 0, **17px 에서 가장 좁고(-0.026em),
24px 을 넘으면 다시 양수**로 돌아선다. 본문을 조이고 큰 제목은 살짝 벌린다.
Pretendard 는 시스템 글꼴이 아니라 브라우저가 이 보정을 대신 해 주지 않으므로 `base.css` 에서 직접 넣는다.

## 지금의 기준

모든 값은 `src/styles/tokens.css` 에만 있다. 나머지 CSS 는 변수만 참조한다.

### 색
- 바탕은 회색(`--paper` #f2f2f7 / 다크 #0b0b0e), 그 위에 흰 카드(`--surface`)를 얹는 iOS 묶음 목록 구성.
- **테두리 대신 채움색**(`--fill-1/2/3`)으로 구분한다. 입력칸·세그먼트 트랙·칩이 전부 이 방식이다.
- 강조는 **짙은 청록 하나**(`--accent`). 보조 동작은 같은 색을 옅게 깐 `--accent-tint` 를 쓴다.
- **호박색(`--now`)은 "지금"에만** 쓴다. 하루 리본의 현재 시각 눈금, 그것뿐이다.
- 회색 글자(`--muted`)는 흰 바탕에서 **5.2:1** 이다. 4.5:1 밑으로 내리지 않는다.
- 다크에서 깊이는 그림자가 아니라 표면 밝기로 낸다(`--paper` → `--surface` → `--surface-sunk`).

### 글자
- Pretendard 한 가족만 쓴다. 굵기는 400/500/600/700 네 단계(`--weight-*`).
- 본문 15px, **폰에서는 16px**. 작은 글(11px)도 폰에서는 12px 로 올린다.
- 자간: 본문 -0.016em, 22px 제목 -0.012em, 28px 이상 +0.008em.
- 시각·분량은 `font-variant-numeric: tabular-nums` 로 자리를 고정한다.

### 모서리·그림자
- 반경 6 / 8 / 12 / 16 / 22 / 알약. 묶는 면은 16, 버튼은 12, 시트는 22.
- 안쪽 요소의 반경 = 바깥 반경 − 안쪽 여백(동심 규칙).
- 얹힌 면은 그림자 대신 색으로 구분한다. **진짜로 떠 있는 것**(대화상자·팝오버·토스트·떠 있는 버튼)만 `--shadow-float`.

### 모션
- `--ease-out`(0.32, 0.72, 0, 1) = 자리를 옮기는 것. `--ease-ui`(0.4, 0, 0.6, 1) = 색·투명도.
- `--ease-spring`(끝에서 살짝 넘겼다 돌아옴)은 **`transform` 에만** 쓴다. 색이나 투명도에 쓰면 중간값이 범위를 벗어나 번쩍인다.
- 누르는 것은 전부 `:active { transform: scale(0.96) }`. hover 는 `@media (hover: hover)` 안에만 둔다(터치 기기에 hover 가 눌어붙지 않게).
- `prefers-reduced-motion` 은 `base.css` 의 전역 블록이 처리한다. 지우지 말 것(E2E 가 검사한다).

### 손가락
- 눌리는 것은 **44px** 밑으로 내려가지 않는다. 보이는 크기를 키우기 싫으면 `::after` 로 눌리는 영역만 넓힌다.
- 노치·홈 인디케이터는 `--safe-t/b/l/r` 로 피한다.
- 하단 탭바는 4칸 + 뒤가 비치는 재질. 추가 버튼은 탭 사이에 끼우지 않고 **바 위에 띄운다**.
- 폰에서 대화상자는 **아래에서 올라오는 시트**가 된다(위쪽 모서리만 둥글게, 손잡이 있음).

### 하루 리본 (`src/features/plan/ribbon.ts`)
화면에서 눈에 띄는 자리는 하나만 쓴다. 그 하나가 **오늘 화면 맨 위의 하루 리본**이다.
근무 시간을 가로로 펼치고, 시각이 정해진 일을 우선순위 색 면으로 얹고, 지금 시각을 호박색으로 짚는다.

### 캘린더
- 넓은 화면: 월간 격자에 제목 칩.
- **폰: 칸에 글자를 넣지 않는다.** 점만 찍고, 날짜를 누르면 아래에 그날 목록을 편다.
  390px 에서 칸 하나는 55px 이라 어떤 제목도 들어가지 않는다.

### 하지 않는 것
- 1px 회색 테두리로 버튼·입력칸 두르기. 채움색을 쓴다.
- 검정으로 꽉 채운 탭·버튼. 강조색이나 흰 조각을 쓴다.
- 머티리얼 문법(가운데 큰 FAB, 잉크 리플).
- 세리프 제목, 크림색 바탕, 대문자로 늘려 쓴 라벨.

## 마크
고텍이(GoTechy) 블로그의 블록 G 를 그대로 쓴다. 네 조각이 맞물려 G 를 이루고,
색(`#016473` `#49d6f3` `#484bcb` `#01a0a5` `#035f68`)은 브랜드 고정값이라 테마를 따르지 않는다.
이것만 예외이고, 화면의 나머지는 청록 강조 하나와 호박색 "지금"을 지킨다.
파비콘·앱 아이콘(`public/favicon.svg`, `public/icons/`)과 사이드바가 같은 도형을 쓴다.
아이콘 PNG 는 `node scripts/make-icons.mjs` 로 파비콘에서 다시 만든다.
워드마크는 소문자 `godo`.

## 어긋나지 않게 하는 장치
- `node scripts/check-tokens.mjs`(`pnpm lint` 에 묶여 있다) — 정의되지 않은 토큰 참조,
  다크 선언 두 블록의 불일치, 라이트 기본값 누락을 막는다.
- `e2e/a11y.spec.ts` — 모든 화면을 라이트·다크로 axe 검사(명도 대비 포함)하고,
  모션 줄이기 설정이 실제로 전환을 끄는지 확인한다.
- 폭별 점검은 320 / 375 / 390 / 768 / 1024 / 1440 에서 가로 넘침과 44px 미만 터치 영역을 본다.
