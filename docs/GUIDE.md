# godo 사용 가이드

나만 쓰는 할 일 앱 **godo**의 전체 기능을 하나씩 따라 해 보며 익히는 문서예요.
각 장에 **따라 해 보기**가 있어서, 앱을 열어 두고 그대로 눌러 보면 됩니다. 처음부터 끝까지 한 번 따라 하면 약 40분이 걸리고, 1~3장만 해도 매일 쓸 수 있어요.

> **먼저 알아둘 것 하나.** 모든 데이터는 **이 브라우저 안에만** 저장돼요(서버도 계정도 없어요). 그래서 편하고 빠르지만, 브라우저 데이터를 지우면 같이 사라져요. 9장의 백업을 꼭 한 번 해 두세요.

---

## 0. 3분 시작하기

1. 앱을 열면 **오늘** 화면이 나와요. 왼쪽이 메뉴, 가운데가 목록이에요. (좁은 화면에서는 아래 탭바와 `메뉴` 버튼)
2. 키보드에서 **`Q`** 를 눌러요. 입력창이 열려요.
3. `내일 오후 3시 치과 예약 p1` 을 입력하고 **Enter**. 입력하는 동안 "내일", "오후 3시", "p1"이 색으로 칠해지는 걸 볼 수 있어요. 앱이 알아들었다는 뜻이에요.
4. **다음 7일** 화면에 방금 할 일이 보여요. 동그라미를 눌러 **완료**하면 4초 동안 취소선으로 남아요. 잘못 눌렀으면 아래에 뜬 **되돌리기** 를 누르세요.
5. **`⌘Z`** (윈도우는 `Ctrl+Z`) 로 언제든 직전 작업을 되돌릴 수 있어요. 삭제, 이동, 날짜 변경 모두요.

여기까지가 기본이에요. 나머지는 필요할 때 하나씩 꺼내 쓰면 돼요.

### 설치해서 앱처럼 쓰기
주소창 오른쪽의 설치 아이콘(또는 브라우저 메뉴 → "앱 설치")을 누르면 독립된 창으로 열리고, **인터넷이 없어도** 동작해요.

## 1. 화면 구성과 기본 개념

### 왼쪽 메뉴
| 메뉴 | 무엇이 보이나요 |
|---|---|
| **받은편지함** | 일단 던져 두는 곳. 프로젝트를 정하지 않은 할 일이 모여요 |
| **오늘** | 오늘 해야 할 일 + 날짜가 지난 일. 시간 지정, 오전, 오후, 저녁, 하루 중으로 나뉘어요 |
| **다음 7일** | 앞으로 일주일 할 일을 날짜별로 |
| **지금 할 수 있는 것** | 시작일이 됐고, 보류·막힘이 없는 일만. "당장 손댈 수 있는 것"만 모아 보여줘요 |
| 보기 | 캘린더, 아이젠하워 매트릭스, 타임라인, 습관, 집중, 디데이 |
| 하루 정리 | 오늘 계획하기, 미완료 정리, 주간 리뷰, 요약 보고서, 생산성 |
| 프로젝트 / 라벨 / 필터 | 내가 만든 것들. 즐겨찾기한 프로젝트는 위로 올라와요 |
| 언젠가, 완료, 휴지통, 설정 | 맨 아래 |

### 꼭 알아야 할 개념 4가지
1. **시작일과 마감일은 다른 거예요.**
   - **시작일(날짜)** = "이날부터 할 수 있어/하기로 했어". 이날부터 **오늘** 목록에 나타나요.
   - **마감일** = "늦어도 이날까지". 별도로 정할 수 있어요.
   - 예: "보고서 — 시작일 월요일, 마감일 금요일". 월요일부터 오늘 목록에 나타나고, 금요일이 마감이에요.
2. **우선순위는 P1(가장 높음)~P4(기본)** 예요. 동그라미 테두리 색으로 보여요. 매트릭스 화면은 이 우선순위로 자동 분류돼요.
3. **프로젝트 → 섹션**: 프로젝트 안을 섹션(예: 기획 / 진행 / 완료)으로 나눌 수 있어요. 칸반에서는 섹션이 열이 돼요.
4. **하위 작업**: 할 일 아래에 계속 하위 작업을 만들 수 있어요. 부모를 완료하면 아직 안 끝난 하위 작업도 같이 완료돼요.

## 2. 빠른 추가 — 이 앱의 핵심

`Q` 를 누르면 열려요. **문장으로 쓰면 앱이 알아서 나눠 담아요.**

### 알아듣는 말
| 쓰는 말 | 결과 |
|---|---|
| `내일`, `모레`, `3일 후`, `다음주 수요일`, `12월 3일`, `월말` | 시작일 |
| `오후 3시`, `저녁 7시`, `15:00`, `3시 반` | 시각 |
| `3시부터 4시` | 시각 + 1시간짜리 시간 블록 |
| `아침`, `점심`, `저녁`, `밤` (시각 없이) | 하루 중 구간 |
| `매일`, `매주 월요일`, `매주 월/수/금`, `평일마다`, `2주마다`, `매월 25일`, `매월 마지막 날`, `매년 3월 2일` | 반복 |
| `완료 후 3일마다` | 끝낸 날부터 3일 뒤에 다시 (완료일 기준 반복) |
| `p1` ~ `p4` | 우선순위 |
| `#업무` | 프로젝트 (이름이 길면 `#"사이드 프로젝트"`) |
| `/기획` | 섹션 |
| `@집중필요` 또는 `%집중필요` | 라벨 (없으면 새로 만들어요) |
| `~30분`, `~1시간 30분` | 예상 시간 |
| `!30분` | 시작 30분 전에 알림 |
| `{금요일}`, `마감 금요일`, `금요일까지` | 마감일 |
| 영어도 돼요 | `tomorrow 3pm`, `every monday 9am`, `every weekday` |

> 헷갈리지 않게 **애매하면 인식하지 않아요.** 예를 들어 `3시간 회의`의 "3시간"은 시각이 아니고, `5월 보고서`의 "5월"은 날짜로 만들지 않아요. 입력창 아래 칩과 색칠된 부분을 보면 앱이 무엇을 알아들었는지 바로 알 수 있어요.

### 따라 해 보기 ①
아래를 하나씩 넣어 보고 **칩이 어떻게 바뀌는지** 보세요.

1. `우유 사기` → 받은편지함에 들어가요.
2. `내일 오전 10시 팀 회의 ~1시간 !15분` → 내일 10:00, 예상 1시간, 15분 전 알림.
3. `매주 월요일 오전 9시 주간 보고 p2` → 반복이 잡혀요. (다른 앱이 놓치는 한국어 반복이에요)
4. `금요일까지 계약서 검토 p1 @집중필요` → 마감 금요일, 새 라벨 `집중필요`가 만들어져요.
5. `#` 를 쳐 보세요. 프로젝트가 없으면 아직 안 나와요. 3장에서 만든 뒤 다시 해 보세요.

### 직접 고르기
입력창 아래 버튼(날짜 / 우선순위 / 라벨 / 프로젝트)으로도 고를 수 있어요. **직접 고른 값이 문장에서 알아들은 값보다 우선**해요.

### 여러 개 한꺼번에 넣기
`Shift+Enter` 로 줄을 바꿔 여러 줄을 쓰면 한 번에 여러 개가 만들어져요. **들여쓰면 위 줄의 하위 작업**이 돼요. 메모 앱에서 복사해 붙여넣어도 돼요(`- [ ]` 같은 기호는 자동으로 떼요).

```
장보기
  우유
  계란
    유정란
```

### 키 정리
`Enter` 추가 · `⌘Enter` 추가하고 창 유지(연달아 넣을 때) · `Shift+Enter` 줄바꿈 · `Esc` 닫기

## 3. 할 일 다루기

### 완료·열기·삭제
- 동그라미 클릭 = 완료. **반복 할 일**은 완료하면 다음 회차로 넘어가고, 이번 회차는 "완료" 목록에 기록돼요.
- 행을 클릭(또는 `Enter`)하면 **오른쪽 상세 패널**이 열려요. `Esc` 로 닫아요.
- 삭제하면 **휴지통**으로 가요(30일 보관). 실수해도 복원돼요.

### 상세 패널에서 할 수 있는 것
위에서부터:
| 항목 | 설명 |
|---|---|
| 제목 | 눌러서 바로 수정. `Enter` 로 저장 |
| 날짜 | 눌러서 달력이 열려요. 오늘/내일/이번 주말/다음 주/다음 달/날짜 없음/**언젠가**, 시각, 소요 시간, 하루 중 구간(오전·오후·저녁), **반복** |
| 마감 | 마감일 (시작일과 별개) |
| 우선순위 | P1~P4 |
| 프로젝트 | 프로젝트와 섹션 이동 |
| 라벨 | 여러 개 가능. 검색창에 새 이름을 쓰면 바로 만들어요 |
| 예상 시간 | 15분/30분/1시간/2시간 또는 직접 입력. 오늘 계획의 "용량"에 쓰여요 |
| 설명 | 마크다운으로 메모. `- [ ]` 체크리스트, `**굵게**`, 링크. 저장은 바깥 클릭 또는 `⌘Enter` |
| 하위 작업 | 입력하고 `Enter` |
| 알림 | 정각/5분/15분/30분/1시간/하루 전 등. **확인할 때까지 계속 알리기**를 켤 수도 있어요 |
| 시작 조건 | "다른 할 일이 먼저 끝나야 시작할 수 있어" (막힘), **보류**(지금은 목록에서 숨김) |
| 댓글 | 진행 메모를 시간순으로 남겨요 |
| 활동 기록 | 언제 무엇이 바뀌었는지 |

오른쪽 위 `···` 메뉴: **상단에 고정 / 집중 시작 / 복제 / 템플릿으로 저장 / 링크 복사 / (반복이면) 이번 회차 건너뛰기 / 계획 취소 / 휴지통으로**.
**계획 취소**는 지우지 않고 "안 하기로 한 일"로 기록만 남겨요.

### 따라 해 보기 ②
1. `보고서 초안 작성` 을 추가하고 클릭해서 상세 패널을 여세요.
2. 날짜 → **내일**, 시각 **10:00**, 소요 시간 **1시간 30분**.
3. 마감을 **이번 주 금요일**로. 우선순위를 **P1**로.
4. 예상 시간 **1시간 30분** 선택.
5. 하위 작업에 `자료 조사`, `개요 잡기`, `본문 쓰기` 를 차례로 입력.
6. 알림 → **+ 알림 추가** → **30분 전**.
7. 설명에 `- [ ] 참고 링크 모으기` 를 적고 `⌘Enter`.
8. `Esc` 로 닫고 **다음 7일**에서 확인해 보세요.
9. `⌘Z` 를 몇 번 눌러 하나씩 되돌아가는 걸 보고, `⌘Shift+Z` 로 다시 앞으로 가 보세요.

### 프로젝트·라벨 만들기
- 사이드바 **프로젝트** 옆 `+` → 이름, 색, (원하면) 상위 폴더, 기본 보기. **폴더**로 만들면 다른 프로젝트를 담아요.
- **라벨**은 "상황"이나 "종류"에 써요 (예: 집중필요, 5분컷, 전화). 프로젝트와 달리 한 할 일에 여러 개 붙일 수 있어요.
- 프로젝트 화면의 오른쪽 위 설정 아이콘으로 이름·색·즐겨찾기·삭제를 해요. 삭제해도 안의 할 일은 휴지통에 남아 있어서 되돌릴 수 있어요.

### 따라 해 보기 ③
1. 프로젝트 `업무`, `집` 을 만드세요.
2. `업무` 프로젝트 목록 맨 아래 **섹션 추가** → `기획`, `진행` 을 만드세요.
3. 이제 빠른 추가에 `#업무 /기획 회의 자료 만들기` 를 넣어 보세요. 업무 > 기획에 들어가요.
4. 할 일 왼쪽에 마우스를 올리면 나오는 **손잡이(⋮⋮)** 를 끌어서 순서를 바꿔 보세요.
5. 할 일에 포커스를 두고(`J`/`K`로 이동) **`⌘]`** 를 누르면 바로 위 할 일의 하위 작업이 되고, **`⌘[`** 를 누르면 다시 나와요.

### 여러 개 한꺼번에 고치기
`X` 로 여러 할 일을 선택하면 아래에 바가 떠요: **완료 / 날짜 / 우선순위 / 삭제**.

### 템플릿
자주 반복하는 묶음(예: "여행 준비" 체크리스트)을 **템플릿으로 저장**했다가 불러와요.
- 저장: 상세 패널 `···` → **템플릿으로 저장** (하위 작업까지 같이 저장, 날짜는 "상대 일수"로 저장돼요)
- 불러오기: `⌘K` → 템플릿 이름 검색 → "○○ 템플릿으로 만들기". 설정 > 템플릿에서 이름 변경·삭제.

## 4. 화면별 사용법

### 오늘
- **기한 초과**가 있으면 위에 빨간 띠가 떠요. **하나씩 정리**(미완료 정리 화면으로) 또는 **모두 오늘로**.
- 하루 리본: 근무 시간을 가로로 펼친 띠예요. 시각이 정해진 일이 색 면으로 앉고, **지금 시각은 호박색 눈금**으로 짚어 줘요. 왼쪽 숫자는 예상 시간 합계 / 하루 용량이고, 넘치면 "N시간 넘쳤어요"가 나와요. 용량 숫자를 눌러 오늘만 바꿀 수 있어요.
- 오늘 해야 하는 **습관**이 한 줄로 떠서 바로 체크할 수 있어요.

### 다음 7일 / 지금 할 수 있는 것 / 전체
각각 날짜별, 프로젝트별로 보여줘요. **지금 할 수 있는 것**은 "막힘/보류/시작 전/언젠가"를 뺀 진짜 "지금 가능한" 목록이에요. 할 일이 너무 많아 막막할 때 여기만 보세요.

### 언젠가
"지금은 못 하지만 잊고 싶지 않은 일"을 날짜 없이 보관해요. 달력에서 **언젠가** 를 누르거나 빠른 추가의 날짜 팝오버에서 골라요. 오늘/다음 7일에는 안 나타나서 머리가 맑아져요.

### 정렬·그룹·완료 표시
프로젝트·라벨 화면 위의 **정렬 / 그룹 / 완료한 일 보임** 으로 바꿔요. 선택은 주소(URL)에 저장돼서 새로고침해도 유지되고 링크로 공유도 돼요. **직접 정렬**일 때만 끌어서 순서를 바꿀 수 있어요.

### 검색
`/` 를 누르면 검색 화면이 열려요. 제목, 설명, 댓글, 완료한 일까지 찾아요. 결과가 마음에 들면 **필터로 저장** 으로 사이드바에 고정해 두세요.

## 5. 프로젝트의 5가지 보기

프로젝트 화면 오른쪽 위 탭으로 바꿔요. 단축키: `V L` 목록 · `V K` 칸반 · `V C` 캘린더 · `V T` 타임라인 · `V M` 매트릭스.

### 목록
섹션별로 묶어서 보여줘요. 섹션 제목을 **더블클릭**하면 이름을 바꾸고, `···` 로 칸반 열의 상태를 지정해요.

### 칸반
섹션이 열이에요. 카드를 열 사이로 끌어 옮겨요.
- 처음이면 **"할 일 · 진행 중 · 완료로 시작"** 버튼 한 번으로 세 열이 만들어져요.
- **"완료" 열로 옮기면 실제로 완료 처리**돼요 (섹션에 "이 섹션으로 옮기면 완료" 상태를 붙였기 때문이에요. 열 `···` 메뉴에서 바꿀 수 있어요).
- 카드의 오른쪽 위 손잡이를 키보드로 잡고 `Space` → 방향키 → `Space` 로도 옮겨요.

### 캘린더 (월/주/일)
- **월**: 날짜 칸의 빈 곳을 누르면 그 날짜로 새 할 일을 만들어요. 칩을 다른 날짜로 끌면 날짜가 바뀌어요. **반복 할 일은 앞으로의 날짜에도 연하게(점선) 나타나요.**
- **주/일**: 시간표예요. 빈 시간을 누르면 그 시각으로 추가, 블록을 끌면 시간·날짜 이동, **블록 아래쪽 끝을 끌면 길이 조절**(15분 단위)이에요. 빨간 선이 현재 시각이에요.

### 타임라인
시작일~마감일을 **막대**로 그려요. 막대를 끌면 일정 이동, 오른쪽 끝을 끌면 마감일이 바뀌어요. 날짜 없는 일은 아래에 모이고, **오늘로** 버튼으로 바로 올릴 수 있어요. 2주/4주/8주로 확대·축소해요.

### 아이젠하워 매트릭스
우선순위로 네 칸에 자동으로 나뉘어요: **지금 하기(P1) / 계획하기(P2) / 빠르게 처리(P3) / 나중에·버리기(P4)**. 카드를 다른 칸으로 끌면 우선순위가 바뀌어요.

### 따라 해 보기 ④
1. `집` 프로젝트를 열고 **칸반** 탭 → "할 일 · 진행 중 · 완료로 시작".
2. 각 열의 **작업 추가**로 카드를 3개 만들고, 하나를 "진행 중"으로, 하나를 "완료"로 끌어 보세요.
3. **캘린더 → 주** 에서 내일 시간표의 오전 10시 빈칸을 눌러 `팀 회의` 를 추가하고, 블록 아래 끝을 끌어 1시간으로 늘려 보세요.
4. **매트릭스** 화면에서 카드 하나를 "지금 하기" 칸으로 끌어 보세요. 상세 패널에서 우선순위가 P1로 바뀐 걸 확인하세요.

## 6. 필터 — 나만의 목록 만들기

사이드바 **필터** 옆 `+` 에서 만들어요. 조건을 쓰면 **몇 개가 해당되는지 바로 미리 보여줘요.** 틀린 곳은 위치와 함께 알려줘요.

### 문법
| 쓰는 것 | 뜻 |
|---|---|
| `today` `tomorrow` `overdue` `no date` (한글: `오늘` `내일` `기한초과` `날짜없음`) | 날짜 조건 |
| `7 days` / `next 7 days` | 오늘부터 7일 안 |
| `date before: 10월 30일` `date after: ...` | 기간 |
| `deadline: 금요일` `마감: 금요일` | 마감일 기준 |
| `p1` `p2` `p3` `p4` | 우선순위 |
| `#업무` / `##업무` | 프로젝트 / 하위 프로젝트까지 |
| `/기획` | 섹션 |
| `@집중필요` 또는 `%집중필요` | 라벨 |
| `recurring` `subtask` `blocked` `hold` `someday` `pinned` | 반복 / 하위 작업 / 막힘 / 보류 / 언젠가 / 고정 |
| `postponed >= 3` | 3번 이상 미룬 |
| `estimate > 30m` | 예상 시간이 30분 초과 |
| `search: 계약서` | 제목·설명에 포함 |
| `&` 그리고, `|` 또는, `!` 아님, `( )` 묶음, `,` 목록 나누기 | 조합 |

### 따라 해 보기 ⑤
1. `(오늘 | 기한초과) & p1` — 지금 급한 것
2. `7 days & #업무 & !반복` — 이번 주 업무 중 반복이 아닌 것
3. `postponed >= 3` — 계속 미루는 일 (주간 리뷰의 재료예요)
4. `@5분컷 & 오늘` — 짬이 날 때 처리할 일

이름 규칙: 이름은 `이번 주 급한 것` 처럼 보고 바로 뜻을 알 수 있게 짓는 걸 추천해요.

## 7. 하루 운영 루틴 — 이 앱이 일을 줄여 주는 방식

사이드바 **하루 정리** 에 있어요. 처음엔 아침 계획 하나만 해도 충분해요.

### 오늘 계획하기 (아침, 3분)
사이드바 **하루 정리 → 오늘 계획하기** 로 열어요. 5단계가 괘선 위 번호로 보여요.
1. **어제 정리** — 못 끝낸 일이 있으면 개수가 나와요. "미완료 정리"로 넘어갈 수 있어요.
2. **후보 고르기** — 오늘 할 만한 일을 체크해서 오늘로 담아요.
3. **용량 확인** — 예상 시간 합계가 오늘 용량(설정에서 기본 6시간)을 넘으면 "덜어낼 후보"를 보여주고 한 번에 내일로 밀 수 있어요.
4. **핵심 고르기** — 오늘 꼭 할 일 **최대 3개**.
5. **시간 배치** — 시간이 안 정해진 일을 **빈 시간에 자동으로 제안**해요. 미리보기가 나오고 **"적용"을 눌러야만** 반영돼요. 못 넣은 일은 "마감 전에 들어갈 빈 시간이 없어요" 처럼 이유를 알려줘요.

### 시간대 템플릿 — 일의 종류마다 시간을 정해 두기
머리 쓰는 일은 오전에, 잡무는 오후에 몰고 싶을 때 써요. **설정 > 일반 > 시간대 템플릿**에서 정해요.

- 시간대마다 **이름 · 시각 · 요일 · 어떤 일을 넣을지**(라벨, 우선순위, 예상 시간 하한)를 정해요.
- 조건을 아무것도 안 고르면 **모든 일**이 그 시간대에 들어가요.
- 조건에 맞는 일은 **그 시간대 안에만** 배치돼요. 그 시간이 꽉 차면 근무 시간의 다른 빈자리로 흘러가지 않고 "딥워크 시간대에 들어갈 빈 시간이 없어요"라고 알려 줘요.
- 조건에 맞는 시간대가 없는 일은 지금처럼 근무 시간 전체를 써요.
- 처음이라면 **"딥워크·잡무로 시작하기"** 버튼을 누르세요. 평일 오전 09–12시(1시간 이상 걸리는 일), 오후 14–18시(P3·P4) 두 개가 만들어져요.

### 따라 해 보기 — 시간대 템플릿
1. 설정 > 일반 > 시간대 템플릿에서 **딥워크·잡무로 시작하기**를 누르세요.
2. 라벨 `@딥워크`를 만들고(상세 패널이나 빠른 추가에서 `@딥워크`) 딥워크 시간대의 `@딥워크` 칩을 켜세요.
3. `보고서 초안 @딥워크 ~2시간` 과 `택배 보내기 p4 ~15분` 을 오늘로 추가하세요.
4. 하루 정리 > 오늘 계획하기 > 시간 배치로 가면, 보고서는 오전에, 택배는 오후에 제안돼요. 제안 옆에 시간대 이름이 붙어요.

저녁에는 탭을 **저녁 회고**로 바꿔요: 오늘 한 일 / 못 끝낸 일 처리(내일로·언젠가·취소) / 한 줄 회고.
> 모든 안내가 "다 못 해도 괜찮아요" 어조예요. 계획은 압박이 아니라 정리 도구예요.

### 미완료 정리
날짜가 지난 일을 **카드 한 장씩** 넘기며 결정해요. 진행은 "3 / 12" 로 보여요.
| 키 | 결정 |
|---|---|
| `T` | 오늘로 다시 잡기 |
| `D` | 다른 날로 (달력이 열려요) |
| `I` | 받은편지함으로 |
| `E` | 완료 |
| `S` | 언젠가로 |
| `X` | 삭제 |
| `Backspace` 또는 `Z` | 직전 결정 되돌리기 |

오래 못 하고 있는 일은 카드에 "N일째 못 하고 있어요. 보관할까요?" 띠가 떠요. 끝나면 요약이 나와요.

### 받은편지함 정리
받은편지함 화면 오른쪽 위 **정리 시작 (N)** 을 누르면 한 개씩 크게 보여줘요. 키보드로: 수락(프로젝트·날짜 정해 이동, 숫자 `1`~`9` 로 프로젝트 바로 선택) / 오늘로 / 내일로 / 언젠가 / 삭제 / 건너뛰기.

### 주간 리뷰
오래 묵은 일, 자주 미룬 일, 마감이 지난 일, "다음 행동이 없는 부모"를 사유별로 모아 보여줘요. 각 항목을 **유지 / 오늘로 / 다음 주로 / 언젠가로 / 계획 취소 / 삭제**. 항목에 포커스를 두고 `K` 유지, `T` 오늘, `W` 다음 주, `S` 언젠가, `X` 취소. (삭제는 실수 방지를 위해 단축키가 없어요.) 기준(묵은 일수 14, 미룬 횟수 3)은 화면에서 바꿔요.

### 따라 해 보기 ⑥ (오늘 하루 돌려 보기)
1. 할 일 5개를 넣고 각각 예상 시간을 주세요 (`~1시간` 처럼).
2. **오늘 계획하기** → 후보를 오늘로 담고 용량 막대가 넘치는 걸 확인 → 덜어내기.
3. 핵심 2개를 고르고, **시간 배치** 미리보기를 보고 적용.
4. **캘린더 → 일** 로 가서 배치된 블록을 확인.
5. 밤에 **저녁 회고**.

## 8. 집중, 습관, 디데이, 기록

### 집중 (포모도로)
사이드바 **집중**(또는 상세 패널 `···` → 집중 시작).
- 모드: **포모도로**(기본 25분 집중 + 5분 휴식, 4번마다 긴 휴식) 또는 **스톱워치**.
- 할 일을 연결하면 걸린 시간이 그 할 일의 **실제 시간**으로 쌓여요 (예상 대 실제를 볼 수 있어요).
- 다른 화면으로 가도 타이머는 계속 가고, 화면 아래에 작은 타이머가 떠요. 새로고침해도 이어져요. 탭 제목에도 남은 시간이 보여요.
- 끝나면 소리(설정에서 끌 수 있어요)와 알림. 오늘 완료한 포모 수, 최근 14일 막대 그래프, 할 일별 집중 시간 상위 5개가 보여요.

### 습관
- `새 습관` → 이름, 색, **빈도**(매일 / 요일 선택 / 주 N회), **목표**(체크 / 횟수+단위 예: 8잔), 시작일, 그룹.
- **시간 비워 두기**(유연한 습관 블록): 켜면 "07:00–09:00 사이 30분"처럼 **시간대와 길이**만 정해요. 정해진 시각에 못 박지 않고, 그날 일정에 맞춰 빈자리를 매일 다시 찾아요. 비운 시간은 **오늘 화면**과 **아침 계획 > 시간 배치**에 보이고, 할 일 자동 배치가 그 자리를 피해 가요. 자리를 못 찾으면 이유를 알려 줘요.
- 이번 주 7칸 그리드의 칸을 눌러 체크해요. **횟수 습관**은 누를 때마다 +1, 길게 누르면 값을 직접 입력해요.
- 이름을 누르면 **최근 12주 히트맵**, 현재/최장 연속, 30일 달성률이 나와요.
- **오늘** 화면 위에도 오늘 할 습관이 떠서 거기서 바로 체크할 수 있어요.

### 디데이
큰 숫자(D-12, D-DAY, D+5)로 보여줘요. 시험, 기념일, 마감 같은 것. **매년 반복**을 켜면 생일처럼 해마다 다음 날짜로 넘어가요.

### 생산성
- **카르마 점수와 레벨**: 완료할 때마다 쌓여요(우선순위가 높을수록, 마감 안에 끝낼수록 더 많이). 5일 넘게 밀린 일은 깎여요.
- 일일/주간 목표, **연속 달성** 일수, 최근 30일 막대 그래프.
- 쉬는 요일을 정하거나 **휴가 모드**를 켜면 그동안은 연속이 끊기지 않아요.
- 점수가 부담되면 카르마를 끌 수 있어요.

### 요약 보고서
기간(오늘/이번 주/지난 주/이번 달/직접), 프로젝트, 상태(완료/미완료/전체)를 고르면 **마크다운 보고서**가 만들어져요. **복사**하거나 `.md` 파일로 저장해서 주간 보고에 붙이세요. **이번 주 한 일 / 다음 주 할 일** 빠른 버튼이 있어요.

## 9. 설정, 알림, 백업

`G` `S` 또는 사이드바 맨 아래 **설정**. 탭 8개:

| 탭 | 내용 |
|---|---|
| 일반 | 시간대, 주 시작 요일, 12/24시간, **하루 시작 시각**(새벽 2시에도 어제로 치고 싶을 때), 시작 화면, 새 할 일 기본값, 근무 시간(자동 배치가 씀), 블록 사이 여유, **하루 용량**, 시작 전 할 일 숨기기 |
| 모양 | 라이트/다크/자동, 강조색 6가지, 밀도(기본/촘촘) |
| 사이드바·모듈 | 안 쓰는 화면(캘린더·매트릭스·습관·집중·디데이·타임라인)과 사이드바 항목 끄기 |
| 알림 | 브라우저 알림 권한, 테스트, 기본 알림 시점 |
| 단축키 | 모든 단축키 확인, **원하는 키로 바꾸기**, 충돌 경고, 초기화 |
| 데이터 | 백업·가져오기·스냅샷·휴지통·전체 삭제 |
| 템플릿 | 저장한 템플릿 관리 |
| 정보 | 버전, 저장 방식 |

### 알림
- 할 일에 **날짜와 알림**이 있어야 울려요. 시각이 없으면 근무 시작 시각(기본 09:00)을 기준으로 해요.
- **앱(탭)이 열려 있는 동안** 울려요. 알림 카드에서 **완료 / 10분 뒤 / 1시간 뒤 / 내일 아침 / 열기** 를 고를 수 있어요.
- 앱이 닫혀 있던 동안 놓친 알림은 **다시 열 때 24시간 이내 것까지** 알려줘요.
- 처음에 설정 > 알림에서 **권한 허용**을 눌러야 시스템 알림도 떠요.
- 솔직한 한계: 서버가 없어서, 앱을 완전히 닫아 두면 알림이 울리지 않아요.

### 백업 — 꼭 하세요 (설정 > 데이터)
- **JSON 백업 내보내기**: 모든 데이터가 파일 하나로. 주 1회 정도 받아 두세요.
- **가져오기**: 파일을 고르면 먼저 **미리보기**(몇 개, 경고)를 보여줘요. **병합**(합치기) 또는 **덮어쓰기**(현재 데이터 교체, 확인 단계 있음). Todoist CSV도 가져올 수 있어요. 덮어쓰기를 해도 백업에 설정이 없으면 지금 설정(테마·시간대·단축키)은 그대로 둬요.
- **CSV 내보내기**는 Todoist 형식이라 **하위 작업을 4단계까지**만 담아요(그보다 깊은 하위 작업은 4단계의 형제로 평평해져요). 전부 그대로 남기려면 JSON 백업을 쓰세요.
- **자동 스냅샷**: 앱이 알아서 6시간마다(변경이 있을 때) 백업을 남겨 두고 오래된 건 정리해요. 실수로 망가뜨렸을 때 여기서 **복원**해요. (같은 브라우저 안에 있으므로 브라우저 데이터를 지우면 같이 사라져요. 그래서 파일 백업도 따로 필요해요.)
- **휴지통**: 30일 지난 항목은 앱을 열 때 정리돼요.
- 위험 구역: **모든 데이터 삭제** (입력창에 "삭제"를 직접 써야 해요).

### 여러 탭·여러 창
같은 브라우저에서 앱을 두 탭으로 열어도 안전해요. 한 탭에서 바꾸면 다른 탭이 알아서 다시 읽어요(숨은 탭이면 그 탭으로 돌아올 때 읽어요). 다른 탭이 앱 업데이트를 하면 "새로고침해 주세요" 안내가 나와요.
저장에 실패한 변경이 남아 있는 탭은 다시 읽지 않고 그 사실을 알려 줘요. 그 변경이 화면에서 사라지지 않게 하려는 거예요. 그때는 백업을 받아 두고 새로고침하세요.

### 다른 기기에서 쓰고 싶다면
데이터가 브라우저 안에 있으므로 **자동 동기화는 없어요.** 옮기려면 한쪽에서 JSON 백업을 내보내고 다른 쪽에서 가져오기로 불러오세요.

## 10. 단축키 한눈에

앱 안에서 `?` 를 누르면 같은 표가 떠요. 입력창에 글을 쓰는 중에는 글자 단축키가 꺼져요.

### 이동 — `G` 를 누른 뒤 다음 키
| 키 | 화면 | 키 | 화면 |
|---|---|---|---|
| `G` `I` | 받은편지함 | `G` `C` | 캘린더 |
| `G` `T` | 오늘 | `G` `M` | 매트릭스 |
| `G` `U` | 다음 7일 | `G` `H` | 습관 |
| `G` `N` | 지금 할 수 있는 것 | `G` `F` | 집중 |
| `G` `A` | 전체 | `G` `P` | 생산성 |
| `G` `R` | 주간 리뷰 | `G` `S` | 설정 |

### 만들기·검색
| 키 | 동작 |
|---|---|
| `Q` | 작업 추가 |
| `Shift` `A` | 선택한 할 일에 하위 작업 추가 |
| `/` | 검색 |
| `⌘K` | **명령 팔레트** — 모든 명령, 할 일, 프로젝트, 라벨, 필터, 템플릿을 한 곳에서 검색 |
| `?` | 단축키 도움말 |

### 할 일 다루기 (할 일에 포커스를 둔 뒤)
| 키 | 동작 |
|---|---|
| `J` / `K` | 다음 / 이전 할 일로 이동 |
| `Enter` | 상세 패널 열기 |
| `E` | 완료 / 다시 열기 |
| `X` | 선택 토글 (여러 개 선택) |
| `S` `T` / `S` `M` / `S` `W` / `S` `X` | 날짜를 오늘 / 내일 / 다음 주로, 날짜 지우기 |
| `Y` `1` ~ `Y` `4` | 우선순위 P1 ~ 없음 |
| `P` | 고정 / 고정 해제 |
| `⌘]` / `⌘[` | 들여쓰기 / 내어쓰기 |
| `⌘D` | 복제 |
| `⌘⌫` | 휴지통으로 |

### 기타
| 키 | 동작 |
|---|---|
| `⌘Z` / `⌘Shift Z` | 실행 취소 / 다시 실행 |
| `V` `L` `K` `C` `T` `M` | 프로젝트 보기 전환 (목록/칸반/캘린더/타임라인/매트릭스) |
| `M` | 사이드바 열기·닫기 |
| `Esc` | 패널·창 닫기 |

윈도우는 `⌘` 대신 `Ctrl` 을 써요. **설정 > 단축키**에서 마음대로 바꿀 수 있어요.

> **팁**: `⌘K` 만 외워도 돼요. "캘린더", "다크", "백업" 같은 말을 치면 해당 명령이 나와요.

## 11. 자주 막히는 곳

| 증상 | 해결 |
|---|---|
| 날짜를 썼는데 인식이 안 돼요 | 입력창 아래 칩이 안 보이면 인식 못 한 거예요. `내일`, `다음주 월요일`, `12월 3일` 처럼 쓰거나 날짜 버튼으로 직접 고르세요. 설정 > 일반에서 "스마트 날짜 인식"이 켜져 있는지도 확인하세요 |
| 단축키가 안 먹어요 | 입력창에 커서가 있거나 창이 열려 있으면 글자 단축키가 꺼져요. `Esc` 를 한 번 누르고 다시 해 보세요. `G` 같은 두 키 조합은 1초 안에 이어서 눌러야 해요 |
| 할 일이 오늘 화면에 안 나와요 | 시작일(날짜)이 오늘이거나 지난 일만 나와요. 마감일만 있으면 마감일 당일에 나와요. 보류·언젠가·막힘 상태도 숨겨져요 |
| 완료한 할 일이 사라졌어요 | **완료** 화면에서 날짜별로 볼 수 있어요. 프로젝트 화면에서는 "완료한 일 보임"을 켜세요 |
| 저장 실패 안내가 떠요 | 화면 위 빨간 알림이 닫을 때까지 남아요. 시크릿 모드이거나 브라우저 저장 공간이 가득 찬 경우예요. **지금 설정 > 데이터에서 JSON 백업을 받아 두세요** |
| 알림이 안 울려요 | 설정 > 알림에서 권한을 허용했는지, 할 일에 날짜와 알림이 있는지, 앱 탭이 열려 있는지 확인하세요 |
| 다른 탭에서 바꿨는데 안 보여요 | 보통 자동으로 반영돼요. 안 되면 새로고침하세요 |
| 실수로 많이 지웠어요 | `⌘Z` 를 여러 번 누르세요(최근 100번까지). 그 이전이면 휴지통 → 설정 > 데이터 > 자동 스냅샷 복원 |
| 모양이 어색해요 | 설정 > 모양에서 라이트/다크, 밀도를 바꿔 보세요 |

## 12. 7일 적응 플랜

처음부터 다 쓰려고 하지 마세요. 하루에 하나씩만 늘려 가면 일주일이면 손에 익어요.

| 일차 | 목표 | 할 일 |
|---|---|---|
| **1일** | 던져 넣기 | `Q` 로 머릿속에 있는 걸 전부 받은편지함에 쏟아 내세요. 문장 그대로 써도 돼요 |
| **2일** | 날짜 붙이기 | 받은편지함에서 "정리 시작"으로 오늘/내일/언젠가로 나누세요. `G` `T` 로 오늘만 보기 |
| **3일** | 구조 만들기 | 프로젝트 2~3개, 라벨 2개를 만들고 빠른 추가에 `#` `@` `p1` 을 써 보세요 |
| **4일** | 시간 쓰기 | 예상 시간(`~30분`)을 붙이고 오늘 계획하기를 해 보세요. 용량 막대를 보세요 |
| **5일** | 보기 바꾸기 | 칸반, 캘린더 주 보기, 매트릭스를 한 번씩 열어 보고 `V` 키로 전환해 보세요 |
| **6일** | 반복·습관 | `매주 월요일 ...` 같은 반복 할 일과 습관 1개를 만드세요. 집중 타이머를 한 번 돌려 보세요 |
| **7일** | 주간 리뷰 + 백업 | 주간 리뷰를 하고, 요약 보고서를 뽑고, **JSON 백업을 받으세요** |

### 한 장짜리 체크리스트 (따라 하면서 체크하세요)
- [ ] `Q` 로 문장 하나 넣고 칩 확인
- [ ] 완료 → 되돌리기 → `⌘Z`
- [ ] 상세 패널에서 날짜·마감·우선순위·하위 작업 설정
- [ ] 프로젝트와 섹션 만들고 `#프로젝트 /섹션` 으로 추가
- [ ] 손잡이로 순서 바꾸기, `⌘]` 로 하위 작업 만들기
- [ ] `매주 월요일` 반복 할 일 만들고 완료해서 다음 회차로 넘어가는 것 확인
- [ ] 칸반에서 카드 끌어 옮기기
- [ ] 캘린더 주 보기에서 블록 끌어 시간 바꾸기
